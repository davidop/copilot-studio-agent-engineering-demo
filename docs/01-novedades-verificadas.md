# Novedades que elevan la sesión

**Revisión documental de noviembre de 2026.** Los estados GA/preview y las licencias deben confirmarse en el tenant antes de enseñar funcionalidades en directo.

| Tecnología | Estado / alcance | Valor de demo |
|---|---|---|
| Extensión oficial VS Code | GA, orientada al **Standard harness** | Clonar YAML, editar, comparar y aplicar |
| Copilot Studio MCP Server | Herramientas de desarrollo y administración, según permisos | Operar desde GitHub Copilot / Claude Code |
| Microsoft Copilot harness | Antiguo GitHub Copilot harness, cambio de denominación de octubre de 2026 | Skills, orquestación, evaluación |
| Evaluación de agentes | Funciones diferentes según harness; revisar preview | Calidad y regresión |
| Copilot Agent Kit | Agent Review Pipeline, configuración específica | Gate de release |
| Foundry Agent Service | Algunas funciones de Copilot harness en preview | Extensión arquitectónica opcional |
| Agent Framework .NET / Python | Skills para asistentes de código | Demo adicional pro-code, no equivalencia de harness |

Tres diferencias importantes:

1. **Extensión VS Code para Standard** ≠ flujo de autoría del nuevo Microsoft Copilot harness.
2. **MCP para gestionar Copilot Studio** ≠ MCP utilizado como herramienta de un agente ≠ exponer un agente como herramienta/protocolo.
3. **Apply** actualiza el borrador ≠ **Publish**.
