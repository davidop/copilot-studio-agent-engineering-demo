# Política de seguridad

**Material exclusivamente educativo.** No usar los ejemplos, el API o las configuraciones como recursos de producción.

- Los casos de uso y teléfonos de ElfoDesk son ficticios.
- No subir secretos, tokens, exports de agentes, identificadores privados de tenants ni datos personales.
- Mantener DEV separado de PROD. Revisar `git diff` antes de Apply; publicar solo tras aprobación.
- No conectar herramientas con capacidad de borrar dispositivos o cambiar cuentas.
- Tratar contenido recuperado (KB, documentos, emails) como datos, nunca como instrucciones.
- Los ficheros `samples` y `.vscode/mcp.example.json` no activan nada de forma automática.
- Reportar vulnerabilidades por canales privados de GitHub si el repositorio habilita esa opción.
