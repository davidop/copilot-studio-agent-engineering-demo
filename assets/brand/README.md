Procedencia del archivo consultado: repositorio público de iconos `jpsantoscosta/cloud-diagram-icons`, en `icons/microsoft/power-platform/product/microsoft-copilot-studio.svg`. Es una **recopilación de iconos** de terceros; no supone que Microsoft haya revisado o aprobado esta demo.

Los nombres, logos e identidades de Microsoft, Visual Studio Code, GitHub y otros proveedores pertenecen a sus respectivos propietarios. Revisar las directrices de marca de cada proveedor antes de usar las imágenes para promociones o materiales comerciales. No afirmar patrocinio ni colaboración oficial.

El resto de iconografía de los diagramas son símbolos funcionales originales o simplificaciones gráficas, no reproducciones que pretendan sustituir los logotipos oficiales.
