# Material de identidad visual

El archivo `CopilotStudio_scalable.svg` reproduce el icono de producto de Copilot Studio, incorporado como recurso gráfico para documentar una arquitectura técnica.

Procedencia del archivo consultado: repositorio público de iconos `jpsantoscosta/cloud-diagram-icons`, en `icons/microsoft/power-platform/product/microsoft-copilot-studio.svg`. Es una **recopilación de iconos** de terceros; no supone que Microsoft haya revisado o aprobado esta demo.

Los nombres, logos e identidades de Microsoft, Visual Studio Code, GitHub y otros proveedores pertenecen a sus respectivos propietarios. Revisar las directrices de marca de cada proveedor antes de usar las imágenes para promociones o materiales comerciales. No afirmar patrocinio ni colaboración oficial.

El resto de iconografía de los diagramas son símbolos funcionales originales o simplificaciones gráficas, no reproducciones que pretendan sustituir los logotipos oficiales.

## Hero visual de ElfoDesk

El archivo [`elfodesk-hero.png`](elfodesk-hero.png) es la imagen principal de identidad visual del proyecto.

Se utiliza como cabecera del `README.md` principal y resume visualmente el concepto de la sesión: **Agent Engineering, Copilot Studio, VS Code, GitHub Copilot y espíritu navideño**.

A diferencia de las ilustraciones técnicas del carrusel, esta pieza funciona como **hero de marca y portada del proyecto**, por lo que se mantiene dentro de `assets/brand/`.

Las ilustraciones de arquitectura, flujo, evaluación y Quality Gate se encuentran separadas en [`assets/carousel/originals/`](../carousel/originals/).
